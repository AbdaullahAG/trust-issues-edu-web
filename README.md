# Trust Issues: Git, Code & Trust

An interactive session site for **OWASP Amman**: from your first commit to secure collaboration.

**Live site:** https://abdaullahag.github.io/trust-issues-edu-web/

## What is this?

A single-page, slide-style website used to present the session. Instead of static slides, the presenter clicks through small simulations: how a Git change moves from your working directory to GitHub, what really happens when you delete a pushed secret, how a flood of Pull Requests exhausts a maintainer, and how to review a Pull Request like a security engineer.

## Chapters

`whoami` · Introduction · Open Source Myths · AI × Pull Requests · Git Mental Model · Git Commands · Secrets & History · Identity & Access · Review & Harden · Real-World Attacks · Takeaways · Sources

## Controls

| Key | Action |
|---|---|
| `←` `→` | Previous / next chapter |
| `Enter`, `Space`, `↓` or **Reveal** | Show the next item in the chapter |
| `G` | Chapter menu |
| `F` | Fullscreen |

You can also click the dots at the bottom to jump to a chapter, and link to one directly, for example `.../trust-issues-edu-web/#5`.

## Run it locally

No build step and no dependencies. Open `index.html` in a browser. The pixel font is loaded from Google Fonts, so without internet the page falls back to a monospace font and keeps working.

## Good to know

- All secrets, keys and code shown in the simulations are **fake**, and the simulations are illustrations, not real data.
- Numbers and incidents are cited in the **Sources** chapter. Please check them against the original sources before quoting.
- The repository is served by GitHub Pages. An empty `.nojekyll` file keeps GitHub from processing the files.

## Try it yourself

After the session, add your first contribution to the feedback repository: *(https://abdaullahag.github.io/trust-issues-edu-web/)*.
